# Kevla & Moki — Unity Game 🎮

A collaborative Unity game development project by **Kevin (Andrei)** and **Moka (Tsetseelei)**.

We're building a third-person survival game inspired by Valheim and Rust, featuring exploration, crafting, combat, inventory management, and PvE/PvP gameplay.

## 🛠️ Development

- **Game Engine:** Unity
- **Programming Language:** C#
- **Code Editor:** Visual Studio / VS Code
- **3D Modelling:** Blender
- **Version Control:** Git & GitHub

## 📁 Project Structure

| Folder | Purpose |
|---|---|
| `Assets/Scripts/` | C# scripts for gameplay systems and mechanics. |
| `Assets/Scenes/` | Unity scenes and game environments. |
| `Assets/Prefabs/` | Reusable game objects, items and components. |
| `Assets/Art/` | 3D models, textures and materials. |
| `Assets/UI/` | Inventory, hotbar, stamina and other interface elements. |
| `Packages/` | Unity package dependencies. |
| `ProjectSettings/` | Unity project configuration. |
| `Docs/` | Project documentation and folder explanations. |

## 🌿 Branches

| Branch | Purpose |
|---|---|
| `main` | Stable, shared version of the game. |
| `tsetsei_dev` | Moka's personal development branch. |
| `andrei_dev` | Kevin's personal development branch. |

Changes are developed on individual branches and merged into `main` through pull requests.

## 👥 Team
