# Folder Guide

- **Assets/Scripts** — C# scripts for gameplay mechanics.
- **Assets/Scenes** — Unity scenes and environments.
- **Assets/Prefabs** — Reusable objects such as items and chests.
- **Assets/Art** — 3D models, textures and materials.
- **Assets/UI** — Inventory, hotbar, stamina and HUD elements.
- **Packages** — Unity package dependencies.
- **ProjectSettings** — Unity configuration files.
